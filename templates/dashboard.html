Camera Setup Guide

For Phone Cameras (Iriun):

  1. Install Iriun Webcam app on your phone (Google Play/App Store)
  2. Install Iriun Webcam on your laptop from iriun.com
  3. Connect both devices to the same WiFi network
  4. Open Iriun on both devices
  5. Your phone will appear as Camera 0, 1, or 2 in the system
  6. Add it using the form above with the correct camera number

For Multiple Phones:

You can connect multiple phones simultaneously. Each phone will appear as a different camera number. Add each one separately.

ETsec Multi-Camera System Guide

Adding Multiple Cameras:

  • USB Cameras: Plug in and they will be auto-detected
  • Phone Cameras (Iriun): Connect via WiFi, they appear as USB cameras
  • IP Cameras: Add using RTSP URL (e.g., rtsp://ip:port/stream)
  • Up to 10 cameras can be added simultaneously

For Different Locations:

  • Homes: Front door, back door, garage
  • Offices: Main entrance, reception, server room
  • Retail: Entrance, checkout, storage areas
  • Warehouses: Loading dock, entry gates, restricted zones

Camera Management:

  • Each camera operates independently
  • Enable/disable cameras individually
  • Each camera has its own alert cooldown
  • All cameras log to the same database
