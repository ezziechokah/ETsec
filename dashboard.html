📚 ETsec System Guide

How ETsec Works

ETsec is an AI-powered security system that uses facial recognition to identify people approaching your premises. It distinguishes between authorized personnel, unknown individuals, and blacklisted intruders.

Installation Guide for Different Locations

🏢 For Companies/Offices:

  • Place cameras at entry points (main door, reception, restricted areas)
  • Register all employees in the system
  • Set up multiple cameras covering all angles
  • Connect to office network for remote monitoring

🏠 For Homes:

  • Position camera at main entrance facing approach path
  • Register family members and regular visitors
  • Set up WhatsApp alerts for immediate notification
  • Use old smartphones as additional cameras via Iriun

🏪 For Retail Stores:

  • Install cameras at entrance and checkout areas
  • Register staff and known shoplifters (blacklist)
  • Set up distance-based alerts (2-meter trigger)
  • Monitor back-of-house restricted areas

Setup Steps:

  1. Install Iriun Webcam on laptop and phones
  2. Connect all devices to same WiFi network
  3. Run ETsec on laptop: python etsec_main.py
  4. Access dashboard at http://localhost:5000
  5. Add cameras via IP addresses shown in Iriun
  6. Register faces using the dashboard
  7. Test with different facial appearances

Best Practices:

  • Ensure good lighting for accurate face detection
  • Register faces from multiple angles
  • Update registrations when people change appearance significantly
  • Regularly review logs for system performance
  • Keep backup of database file

Troubleshooting:

  • False alarms: Adjust camera position and lighting
  • Face not recognized: Re-register with better lighting
  • WhatsApp not sending: Check phone number format (+255759105607)
  • Camera disconnected: Restart Iriun on the phone
